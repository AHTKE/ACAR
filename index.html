        كل خاصية بملف مستقل: Excel (.xlsx) أو تقرير PDF — عند الضغط تختار بنفسك: تحميل على الجهاز أو رفع إلى Google Drive.

        ربط Google Drive

        اربط حسابك مرة واحدة، وبعدها كل ملف تصدير بيترفع عليه أوتوماتيك، وتقدر كمان ترفع أي ملف من جهازك.

        جارٍ التحقق من حالة الربط…
        للتفعيل (مرة واحدة): أنشئ مشروعاً في Google Cloud Console ← فعّل Drive API ← املأ OAuth consent screen (External) وأضف حسابك كـ Test user ← أنشئ OAuth client ID من نوع Web application بـ Redirect URI:
        ثم ضع GOOGLE_CLIENT_ID و GOOGLE_CLIENT_SECRET في إعدادات الموقع ← Secrets، وأعد النشر.

        المزامنة السحابية

        نسخة كاملة من كل بياناتك (العملاء، الموردون، الدواخل والخوارج، الشركاء، الجمعيات) بتترفع على فولدر «نظام الإدارة — المزامنة» داخل درايفك. تقدر تفتحه من أي جهاز، ودرفايف بيحفظ نسخة سابقة لكل تعديل — يعني تاريخ بياناتك كله محفوظ عندك.

        لم تُفحص المزامنة بعد

        🔗 الصق رابط فولدر مشترك من درايفك عشان أي جهاز يقدر يستلم الداتا منه. لو فاضي — التطبيق هينشئ فولدر تلقائياً باسم «نظام الإدارة — المزامنة».
